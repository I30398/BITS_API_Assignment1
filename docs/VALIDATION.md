## Reproducing the checkpoint

Follow README.md to start the local server and schedule. Run the tests and
`python -m src.verify --wait-scheduled`. To preserve a new immutable review,
run `python scripts/freeze_evidence.py --output evidence/NEW_REVIEW_NAME` after
capturing new screenshots and generating the draft report. Existing frozen
folders are never overwritten.
