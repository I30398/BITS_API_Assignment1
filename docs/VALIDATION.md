# Assignment I local review validation

The revised code was verified on 25 October 2026. This is a local review
checkpoint; actual cloud hosting, group details and the uploaded demonstration
video remain outside this checkpoint.

## Verified results

- Seven regression tests pass. They exercise training-only preprocessing,
  unseen categories, the stratified split, interrupted publication, concurrent
  CSV readers/writers, cross-process JSON logging and categorical association.
- Fourteen runtime checks pass on macOS and in the Linux Docker package.
- Each environment completed at least two actual scheduled parent cycles with
  the active 120-second interval and concurrency of one.
- The evidence accepts only parent run IDs whose completion history matches the
  current runtime/API source fingerprint. Report layout changes are excluded
  from this fingerprint because they do not change pipeline behavior.
- The project .venv installs from the lock file without dependency conflicts.
  The one-command local launcher completes a full cycle against the dashboard.
- Both trained models include their train-fitted imputation, scaling and
  categorical encoding. All 19 original predictors appear once; the customer ID,
  target and duplicate normalised columns are excluded from model inputs.
- The review report has 11 pages. Every rendered page was inspected at original
  resolution, and all table cells were checked against the rendered PDF text.
  The frozen report is byte-identical to the reviewed document.
- All 38 files listed in the frozen local inventory passed SHA256 checks.

## Frozen evidence

`evidence/local-review` contains the copied local tables, charts, structured
logs, dashboard screenshots, API responses, model metrics and reviewed Word
report. Its inventory covers only the packaged files. Model binaries remain in
live outputs and are regenerated by the workflow; they are not copied into the
review snapshot. `verification.json` also catalogues the original live outputs.

`evidence/docker-review` contains the independently captured Linux runtime,
metrics and passing verification. The temporary Docker test project and its
volumes were removed after these files were exported. The primary Python-based
local dashboard remains available on port 4207.

The live dashboard retains failed development runs from the initial dashboard
artifact compatibility check. That defect was corrected before final
verification. The frozen checks distinguish current-source scheduled successes
from earlier development history; the historical failures were not deleted.

## Reproducing the checkpoint

Follow README.md to start the local server and schedule. Run the tests and
`python -m src.verify --wait-scheduled`. To preserve a new immutable review,
run `python scripts/freeze_evidence.py --output evidence/NEW_REVIEW_NAME` after
capturing new screenshots and generating the draft report. Existing frozen
folders are never overwritten.

The deadline and grading authority remain the faculty's assignment brief.
These checks demonstrate implementation behavior; they do not predict marks.
